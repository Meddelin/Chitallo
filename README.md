# pdfer

Минималистичная читалка PDF с локальным переводом EN→RU. Windows, Tauri 2.

Выделите предложение — рядом появится перевод. Alt+клик — перевод целого абзаца.
Одной кнопкой переводится вся книга: готовые страницы сохраняются на диск,
клавиша T переключает оригинал и перевод, процесс можно прервать и продолжить
в любой момент. Перевод выполняет локальная модель — без интернета и подписок.

## Возможности

- **Чтение**: непрерывная прокрутка, 1/2/авто колонок, зум с якорем в точке
  курсора, тёмная тема, оглавление и внутренние ссылки, история переходов
  (Alt+←/→), запоминание позиции по каждой книге
- **Перевод выделенного и абзацев** (Alt+клик) — локальная модель
  HY-MT1.5-7B через llama.cpp, с контекстом абзаца
- **Перевод всей книги** — фоновый ран с паузой и продолжением; готовые
  страницы сохраняются и открываются офлайн, вёрстка абзацев и фигуры
  оригинала сохраняются
- **Глоссарий книги** — характерные термины добираются из текста
  статистически, переводятся моделью и применяются при переводе; правится
  вручную
- **Поиск по книге** (Ctrl+F) — по оригиналу и по готовому переводу
- **Командная палитра** (Ctrl+K): команды, «страница N», переключение книг,
  запуск поиска; оверлей клавиш — `?`
- **Библиотека** с обложками, прогрессом чтения и живым сканом папки
- **«Спросить»** (Ctrl+J) — вопросы по книге; использует Claude Code
  (опционально, требует установленный `claude` и интернет)

## Приватность

Книги, переводы и глоссарии не покидают компьютер: модели скачиваются один
раз и работают локально. Единственное исключение — опциональная функция
«Спросить»: вопрос и фрагмент открытой книги отправляются в Claude по явному
действию.

## Сборка

Требуется: Windows 10/11, Node.js 20+, Rust (stable), инструменты сборки MSVC.

```sh
npm install
npm run tauri dev     # разработка (Vite + HMR)
npm run tauri build   # релизная сборка и инсталлятор
```

Инференс выполняет `llama-server.exe` (llama.cpp), который приложение ищет в
`%APPDATA%\com.stas.pdfer\llama\llama-server.exe`; веса моделей лежат в
`%APPDATA%\com.stas.pdfer\models\`. В дев-режиме llama-server кладётся туда
вручную, веса можно скачать из приложения; в дистрибутив llama-server входит,
веса скачивает само приложение.

Иконка генерируется из `src-tauri/icons/icon.svg`:

```sh
npx tauri icon src-tauri/icons/icon.svg
```
