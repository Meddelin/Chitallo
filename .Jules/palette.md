## 2026-10-10 - Adding aria-labels to icon-only buttons\n**Learning:** The application extensively uses the `t(...)` localization function for `title` attributes on icon-only buttons. Screen readers rely on `aria-label` for accurate announcement of these elements.\n**Action:** Ensure that whenever an icon-only button is implemented and given a `title` for hover tooltips, an identical `aria-label` using the same localization key is also applied to guarantee screen reader accessibility.
