# Chitallo

Минималистичная читалка PDF, которая переводит книги целиком — на вашем
компьютере. Windows и macOS, Tauri 2.

[English version](README.md)

Выделите предложение — рядом появится перевод. Alt+клик переводит абзац целиком.
Одной кнопкой переводится вся книга: готовые страницы сохраняются на диск,
клавиша `T` переключает оригинал и перевод, процесс можно прервать и продолжить
в любой момент. Перевод выполняет локальная модель — без интернета и подписок,
ничего не уходит с компьютера.

Язык интерфейса — и язык, **на который** переводятся книги — русский или
английский: выбирается при первом запуске и меняется в настройках.

## Возможности

- **Чтение**: непрерывная прокрутка, 1/2/авто колонок, зум с якорем в точке
  курсора, тёмная тема, оглавление и внутренние ссылки, история переходов
  (Alt+←/→), запоминание позиции по каждой книге
- **Перевод выделенного и абзацев** (Alt+клик) — локальная модель HY-MT1.5-7B
  через llama.cpp, с контекстом абзаца
- **Перевод всей книги** — фоновый ран с паузой и продолжением; готовые
  страницы сохраняются и открываются офлайн, вёрстка абзацев восстанавливается,
  а рисунки, таблицы и формулы переносятся вырезками оригинала в высоком
  разрешении
- **Термины книги** — список терминов на каждую книгу: они добираются из текста
  статистически, на книге на любом языке и без всякой модели, а модель терминов
  дописывает категорию, определение в одну строку и — только если книга не на
  вашем языке — перевод. Список перестал быть шагом перевода: перевод
  подставляет его в промпт, граф знаний забирает понятия уже с типом и
  объяснением, а «Спросить» читает их оттуда. Файл — простой текст, строка на
  термин, правится вручную
- **Поиск по книге** (Ctrl+F) — по оригиналу и по готовому переводу
- **Командная палитра** (Ctrl+K): команды, «страница N», переключение книг,
  запуск поиска; оверлей клавиш — `?`
- **Библиотека** с обложками, прогрессом чтения и живым сканом папки
- **Граф знаний** — вторая половина библиотеки: из каждой книги добываются
  понятия, книги с общими понятиями связываются между собой, а «Спросить»
  заглядывает туда раньше, чем куда-либо ещё
- **Экспорт** готового перевода в PDF (с иллюстрациями оригинала) или HTML —
  одна кнопка, файл сразу в «Загрузках»
- **«Спросить»** (Ctrl+J) — вопросы по книге через Claude Code. Ответ — проза,
  пока картинка не заслужит своё место: в нём могут быть набранные формулы,
  график по числам из книги (с видом таблицей) или схема. Опционально, и это
  одна из двух вещей, которым нужна сеть, — см. «Приватность».

## Приватность

Книги, переводы и глоссарии не покидают компьютер: модель скачивается один раз
и работает локально. Наружу уходят три вещи, все — через Claude Code и все по
явному действию.

«Спросить» отправляет вопрос, фрагмент открытой книги и короткую выписку из
графа знаний: названия понятий, заголовки книг, где они встречаются, номера
страниц и пару заголовков по соседству, — чтобы ответ начинался с вашей
собственной библиотеки. Однострочное описание понятия уходит только тогда, когда
это понятие есть в открытой статье или в книге, открытой прямо сейчас.

«Разбирать открытые статьи через Claude Code» спрашивает у Claude Code, что
означают термины открыто опубликованной статьи. Уходят заголовок и авторы,
ключевые слова и тема из метаданных файла, а также термины из списка терминов
этого файла — то, что добыла статистика, и то, что вы вписали туда сами. Ни
определений, ни страниц, ни самого файла. По умолчанию выключено, а
лицензионную книгу — и всё, чьё происхождение неясно, — читает локальная модель
на этом компьютере.

«Разрешить поиск в интернете» — единственный переключатель, который выводит
дальше Anthropic. Когда он включён, Claude Code может по ходу ответа выполнить
поиск или открыть страницу, а значит ваш вопрос — и всё, что нужно, чтобы его
найти, — попадёт в поисковик и на сайты, которые тот вернёт. По умолчанию
выключено: без него «Спросить» не получает никаких инструментов вообще. Граф
читается раньше всего в обоих случаях.

## Зависимости

**Chitallo не приносит с собой ничего, кроме Chitallo.** Ни весов моделей, ни движка
инференса, ни рантайма. У каждой функции ровно одна предписанная зависимость на
платформу, и приложение честно говорит, когда её нет — экран первого запуска
проводит через всё по шагам.

| Для чего | Как поставить | Что перестаёт работать без неё |
| --- | --- | --- |
| Движок перевода | `winget install llama.cpp` / `brew install llama.cpp` | весь перевод |
| Модель перевода | скачивается с экрана настройки (4,6 ГБ, один раз) | весь перевод |
| «Спросить» | [Claude Code](https://code.claude.com/docs/en/setup) + подписка Claude Pro или Max | только панель «Спросить» |

Chitallo ищет `llama-server` в PATH, в `~/.local/bin`, в каталогах Homebrew и
WinGet, а также в `<app data>/llama`, если вы положили сборку туда сами.
Переменная `CHITALLO_LLAMA_SERVER` задаёт путь явно; `CHITALLO_CLAUDE_BIN` — то же
самое для CLI Claude Code.

Если на порту 11544 уже слушает ваш собственный `llama-server`, Chitallo
использует его и никогда не трогает — ваш настроенный инстанс остаётся вашим.

| [HY-MT1.5-7B](https://huggingface.co/tencent/HY-MT1.5-7B-GGUF) (Tencent) | перевод книг | 4,6 ГБ | Hunyuan Community License — бесплатно, включая коммерческое использование; **не действует в ЕС, Великобритании и Южной Корее** |
| [Qwen3.5-4B](https://huggingface.co/unsloth/Qwen3.5-4B-GGUF) (Alibaba) | модель терминов — категории, определения и проверка терминов книги, а если книга не на вашем языке — и их перевод (опционально) | 2,7 ГБ | Apache-2.0 |

Скачивание — только по явному действию пользователя, с лицензией на виду.
Докачка продолжается с места обрыва и переживает перезапуск приложения; готовый
файл сверяется с опубликованным SHA-256 до первого использования.

Веса лежат в `<app data>/models` —
`%APPDATA%\com.stas.pdfer\models` на Windows,
`~/Library/Application Support/com.stas.pdfer/models` на macOS.

## Сборка из исходников

Требуется Node.js 20+, Rust (stable) и инструменты платформы: MSVC build tools
на Windows, Xcode command line tools на macOS.

```sh
npm install
npm run tauri dev     # разработка (Vite + HMR)
npm run tauri build   # релизная сборка и инсталлятор
```

`npm run typecheck` прогоняет TypeScript по фронтенду без сборки.

Иконка генерируется из `src-tauri/icons/icon.svg`:

```sh
npx tauri icon src-tauri/icons/icon.svg
```

## Как всё устроено

Tauri 2 · React 19 · TypeScript · Tailwind CSS 4 · PDF.js · llama.cpp

- `src/` — читалка. `App.tsx` владеет поверхностью чтения и тулбаром,
  `booktranslate.ts` ведёт перевод всей книги, `paragraphs.ts` и `crops.ts`
  восстанавливают структуру страницы, `export.ts` собирает PDF/HTML/TXT,
  `i18n.ts` хранит все видимые строки на обоих языках.
- `src-tauri/src/` — нативная половина. `lib.rs` управляет процессами
  llama-server, качает веса и запускает CLI Claude Code; `platform.rs` находит
  внешние бинарники и меряет свободное место; `print.rs` печатает HTML в PDF
  через WebView2 на Windows и NSPrintOperation на macOS.

Версии и лицензии сторонних компонентов — в приложении: «Перевод ▾» →
«О Chitallo».
