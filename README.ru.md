# Chitallo

Минималистичная читалка PDF, которая переводит книги целиком — на вашем
компьютере. Windows и macOS, Tauri 2.

[English version](README.md)

Выделите предложение — рядом появится перевод. Alt+клик переводит абзац целиком.
Одной кнопкой переводится вся книга: готовые страницы сохраняются на диск,
клавиша `T` переключает оригинал и перевод, процесс можно прервать и продолжить
в любой момент. Перевод выполняют две локальные модели — одна пишет черновик,
другая перечитывает готовое и правит язык, — без интернета и подписок, ничего
не уходит с компьютера.

Язык интерфейса — и язык, **на который** переводятся книги — русский или
английский: выбирается при первом запуске и меняется в настройках.

## Возможности

- **Чтение**: непрерывная прокрутка, 1/2/авто колонок, зум с якорем в точке
  курсора, тёмная тема, оглавление и внутренние ссылки, история переходов
  (Alt+←/→), запоминание позиции по каждой книге
- **Перевод выделенного и абзацев** (Alt+клик) — локальная модель
  TranslateGemma-12B-it через llama.cpp, с контекстом абзаца. В один проход —
  потому что ответа здесь ждут, глядя в экран
- **Перевод всей книги, шаг первый — черновик** — фоновый ран с паузой и
  продолжением; готовые страницы сохраняются и открываются офлайн, вёрстка
  абзацев восстанавливается, а рисунки, таблицы и формулы переносятся вырезками
  оригинала в высоком разрешении. TranslateGemma идёт абзац за абзацем и в
  каждый промпт кладёт предыдущий абзац оригинала **и** перевод, уже сделанный
  для этой книги: без этого окна местоимения теряют то, на что указывают, время
  плывёт от абзаца к абзацу, а обращение гуляет между «ты» и «вы» внутри одной
  главы
- **Перевод всей книги, шаг второй — правка стиля** — Gemma 4 26B-A4B-it
  перечитывает готовый перевод, намеренно не видя оригинала, и правит
  согласование, падежи, опечатки, нечитаемые символы и регистр — по терминам
  самой книги и по стилевому руководству. Это отдельный ран, который запускают
  руками, и он необязателен: черновика достаточно, чтобы книга была переведена
  целиком
- **Термины книги** — список терминов на каждую книгу: простой текст, строка на
  термин, правится вручную. Сначала локальная модель читает книгу — начальные
  страницы и страницы вразбивку по всей остальной, — понимает, о чём она и в
  какой традиции написана, и только потом называет термины и пишет определения
  внутри этой рамки; именно это удерживает за бортом сквозные примеры самой
  книги и не даёт переводить устоявшийся термин по словам. Проход без модели
  никуда не делся и по-прежнему пишет на диск, так что на машине без модели
  терминов всё равно будут термины, их страницы и частоты. Список перестал быть
  шагом перевода: перевод подставляет его в промпт, граф знаний забирает
  понятия уже с типом и объяснением, а «Спросить» читает их оттуда
- **Поиск по книге** (Ctrl+F) — по оригиналу и по готовому переводу
- **Командная палитра** (Ctrl+K): команды, «страница N», переключение книг,
  запуск поиска; оверлей клавиш — `?`
- **Библиотека** с обложками, прогрессом чтения и живым сканом папки
- **Граф знаний** — вторая половина библиотеки: из каждой книги добываются
  понятия, книги с общими понятиями связываются между собой, а «Спросить»
  заглядывает туда раньше, чем куда-либо ещё
- **Экспорт** готового перевода в PDF (с иллюстрациями оригинала) или HTML —
  одна кнопка, файл сразу в «Загрузках»
- **«Спросить»** (Ctrl+J) — вопросы по книге через Claude Code. Ответ — проза,
  пока картинка не заслужит своё место: в нём могут быть набранные формулы,
  график по числам из книги (с видом таблицей) или схема. Опционально, и это
  одна из двух вещей, которым нужна сеть, — см. «Приватность».

## Приватность

Книги, переводы и глоссарии не покидают компьютер: модели скачиваются один раз
и работают локально. Наружу уходят три вещи, все — через Claude Code и все по
явному действию.

«Спросить» отправляет вопрос, фрагмент открытой книги и короткую выписку из
графа знаний: названия понятий, заголовки книг, где они встречаются, номера
страниц и пару заголовков по соседству, — чтобы ответ начинался с вашей
собственной библиотеки. Однострочное описание понятия уходит только тогда, когда
это понятие есть в открытой статье или в книге, открытой прямо сейчас.

«Разбирать открытые статьи через Claude Code» спрашивает у Claude Code, что
означают термины открыто опубликованной статьи. Уходят заголовок и авторы,
ключевые слова и тема из метаданных файла, а также термины из списка терминов
этого файла — то, что добыла локальная модель, и то, что вы вписали туда сами.
Ни определений, ни страниц, ни самого файла. По умолчанию выключено, а
лицензионную книгу — и всё, чьё происхождение неясно, — читает локальная модель
на этом компьютере.

«Разрешить поиск в интернете» — единственный переключатель, который выводит
дальше Anthropic. Когда он включён, Claude Code может по ходу ответа выполнить
поиск или открыть страницу, а значит ваш вопрос — и всё, что нужно, чтобы его
найти, — попадёт в поисковик и на сайты, которые тот вернёт. По умолчанию
выключено: без него «Спросить» не получает никаких инструментов вообще. Граф
читается раньше всего в обоих случаях.

## Зависимости

**Chitallo не приносит с собой ничего, кроме Chitallo.** Ни весов моделей, ни движка
инференса, ни рантайма. У каждой функции ровно одна предписанная зависимость на
платформу, и приложение честно говорит, когда её нет — экран первого запуска
проводит через всё по шагам.

| Для чего | Как поставить | Что перестаёт работать без неё |
| --- | --- | --- |
| Движок перевода | одна команда, и какая именно — зависит от видеокарты (ниже) | весь перевод |
| Модель черновика | скачивается с экрана настройки (7,3 ГБ, один раз) | весь перевод |
| Модель правки и терминов | скачивается в «Настройках» → «Модели» (14,2 ГБ, один раз; хочет 16 ГБ VRAM и 32 ГБ оперативной памяти) | правка стиля, термины книги, граф знаний |
| «Спросить» | [Claude Code](https://code.claude.com/docs/en/setup) + подписка Claude Pro или Max | только панель «Спросить» |

### Какая сборка llama.cpp — ваша

Команда по-прежнему одна на машину, и запасных вариантов нет, — но какая
именно, зависит от карты, потому что `winget install llama.cpp` ставит сборку
под **Vulkan**: в манифесте winget для пакета `ggml.llamacpp` поле
`InstallerUrl` указывает на `llama-b<NNNNN>-bin-win-vulkan-x64.zip`. Для AMD и
Intel это правильный ответ. Для NVIDIA — неправильный.

- **macOS** — `brew install llama.cpp`. Metal, выбирать нечего.
- **Windows, видеокарта AMD или Intel** — `winget install llama.cpp`.
- **Windows, видеокарта NVIDIA** — сборка под CUDA. Пакета нет, есть три архива
  на [странице релизов llama.cpp](https://github.com/ggml-org/llama.cpp/releases).

Возьмите все три из **одного и того же номера сборки** и распакуйте в
`%APPDATA%\com.stas.pdfer\llama` — каталог, куда Chitallo смотрит раньше, чем
куда-либо ещё:

| Архив | Что внутри |
| --- | --- |
| `llama-b<NNNNN>-bin-win-cpu-x64.zip` | `llama-server.exe` и остальные исполняемые файлы |
| `llama-b<NNNNN>-bin-win-cuda-13.3-x64.zip` | `ggml-cuda.dll` — бэкенд CUDA, и больше ничего |
| `cudart-llama-bin-win-cuda-13.3-x64.zip` | библиотеки рантайма CUDA |

В архиве с CUDA лежит одна библиотека бэкенда, так что сам по себе он не
установка: без первого нечего запускать, без третьего то, что есть, не
стартует. Если в этом каталоге уже лежит старая сборка под Vulkan, удалите
оттуда `ggml-vulkan.dll`: llama.cpp подхватывает рядом с бинарником все
библиотеки бэкендов, какие найдёт, и с двумя зарегистрированными одна и та же
карта предлагается приложению дважды.

**Берите архивы 13.3, а не 12.4.** CUDA 12.4 старше compute capability 12.0:
на карте 50-й серии llama-server загрузит модель, начнёт генерировать и умрёт с
`no kernel image is available for execution on the device`.

Проверка — `llama-server --list-devices`: одна строка с названием вашей карты,
`CUDA0`, если вы пошли путём NVIDIA, и `Vulkan0`, если нет.

### Что нужно машине и сколько это стоит

Машина, на которую всё это рассчитано, — дискретная видеокарта примерно с 16 ГБ
VRAM и 32 ГБ оперативной памяти. Важны оба числа, и второе стоит здесь не для
красоты: модель правки и терминов — это 14,2 ГБ весов, и на карте, которая не
вмещает их целиком, Chitallo уводит в оперативную память столько экспертных
слоёв, сколько придётся, а читать их приходится заново на каждый
сгенерированный токен. Меньше примерно 20 ГБ оперативной памяти — и приложение
отказывается поднимать эту модель, вместо того чтобы дать машине уйти в своп:
оно прямо об этом говорит, а всё, чему эта модель не нужна, продолжает
работать.

Две модели не делят карту, а сменяют друг друга. Запуск сервера правки и
терминов гасит сервер черновика, а последняя функция, отпустившая его,
поднимает черновик обратно. Плата за это — загрузка модели, меньше минуты; а
взамен та модель, которая сейчас работает, получает всю карту целиком — и для
редактора это разница между экспертами в видеопамяти и экспертами в
оперативной. Ничего при этом не теряется: правка стиля читает то, что написал
черновик, — одновременно они не могли работать в принципе. Ваш собственный
`llama-server`, если вы подняли его сами, не гасится ни ради этого, ни ради
чего-либо ещё.

Честная цена, на той самой книге в 838 страниц, на которой всё это делалось:
черновик — порядка двух часов, правка стиля — ещё до четырёх-пяти, и они не
накладываются друг на друга. Примерно три четверти часа на сотню страниц за оба
шага. Глава — это чашка кофе, книга — вечер. Правка стиля по-прежнему сделана
отдельной кнопкой, а не второй половиной «Перевести книгу», именно поэтому: она
и медленнее, и необязательна.

Это арифметика по скорости, измеренной на этой карте, а не секундомер над целой
книгой. Панель показывает оценку по вашей собственной книге, как только
досчитает первую страницу.

Chitallo ищет `llama-server` сначала в `<app data>/llama`, затем в
`~/.local/bin`, в каталогах Homebrew и WinGet и только потом в PATH: сборка,
которую вы положили руками, всегда выигрывает у той, что поставил менеджер
пакетов. Переменная `CHITALLO_LLAMA_SERVER` задаёт путь явно;
`CHITALLO_CLAUDE_BIN` — то же самое для CLI Claude Code.

Портов два. На 11544 живёт модель черновика, на 11545 — модель правки и
терминов, и карту они передают друг другу, как описано выше. Если на любом из
этих портов уже слушает ваш собственный `llama-server`, Chitallo берёт его как
есть и никогда не трогает: не поднимает второй, ничего в вашем не
перенастраивает, не гасит его, закончив, и не гасит его, чтобы освободить место
другой модели. Ваш настроенный инстанс остаётся вашим.

## Модели

| Модель | Роль | Размер | Лицензия |
| --- | --- | --- | --- |
| [TranslateGemma-12B-it](https://huggingface.co/bullerwins/translategemma-12b-it-GGUF) (Google) | перевод книг, шаг первый — черновик | 7,3 ГБ | Gemma Terms of Use |
| [Gemma 4 26B-A4B-it](https://huggingface.co/unsloth/gemma-4-26B-A4B-it-qat-GGUF) (Google) | шаг второй — правка стиля; и модель терминов: категории, определения и проверка терминов книги, а если книга не на вашем языке — и их перевод (опционально) | 14,2 ГБ | Gemma Terms of Use |

Обе ссылки ведут не в репозитории самой Google, а на перезаливки сообщества.
Репозитории издателя закрыты ручным одобрением, а Chitallo качает без токена
Hugging Face и попасть туда не может.

Скачивание — только по явному действию пользователя, с лицензией на виду.
Докачка продолжается с места обрыва и переживает перезапуск приложения; готовый
файл до первого использования сверяется с SHA-256 файла на зеркале — тем, что
прибит в `src-tauri/src/lib.rs`.

Веса лежат в `<app data>/models` —
`%APPDATA%\com.stas.pdfer\models` на Windows,
`~/Library/Application Support/com.stas.pdfer/models` на macOS.

## Сборка из исходников

Требуется Node.js 20+, Rust (stable) и инструменты платформы: MSVC build tools
на Windows, Xcode command line tools на macOS.

```sh
npm install
npm run tauri dev     # разработка (Vite + HMR)
npm run tauri build   # релизная сборка и инсталлятор
```

`npm run typecheck` прогоняет TypeScript по фронтенду без сборки.

Иконка генерируется из `src-tauri/icons/icon.svg`:

```sh
npx tauri icon src-tauri/icons/icon.svg
```

## Как всё устроено

Tauri 2 · React 19 · TypeScript · Tailwind CSS 4 · PDF.js · llama.cpp

- `src/` — читалка. `App.tsx` владеет поверхностью чтения и тулбаром,
  `booktranslate.ts` ведёт перевод всей книги, `paragraphs.ts` и `crops.ts`
  восстанавливают структуру страницы, `export.ts` собирает PDF/HTML/TXT,
  `i18n.ts` хранит все видимые строки на обоих языках.
- `src-tauri/src/` — нативная половина. `lib.rs` управляет процессами
  llama-server, качает веса и запускает CLI Claude Code; `platform.rs` находит
  внешние бинарники и меряет свободное место; `print.rs` печатает HTML в PDF
  через WebView2 на Windows и NSPrintOperation на macOS.

Версии и лицензии сторонних компонентов — в приложении: «Перевод ▾» →
«О Chitallo».
